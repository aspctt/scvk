scvk

A native Vulkan renderer for SimCity 4.

SimCity 4 shipped in 2003 with a DirectX 7 renderer and an unfinished OpenGL one. scvk replaces the renderer with one built on Vulkan, loaded as a DLL plugin through the game's own plugin system.

Status

Early preview. The region view, cities, menus and loading screens all draw, windowed, full screen or borderless, with lighting that matches the DirectX renderer. So far it has been tested on a single NVIDIA graphics card, so expect problems on other hardware, and save often.

Known issues:

  • The interface sometimes flickers for a single frame.
  • Scrolling while zoomed out is slower than DirectX, by roughly 40% on average in a large city.
  • The game has stopped responding twice in testing, once after leaving the Big City Tutorial and once while exiting to Windows. Neither has happened again since.

System Requirements

  • SimCity 4 Deluxe, game version 641. Older versions are untested.
  • Windows 10 or 11.
  • A graphics card and driver with Vulkan support.
  • The Microsoft Visual C++ v14 Redistributable (x86). SimCity 4 is a 32-bit game, so it needs the x86 one even on 64-bit Windows.
  • sc4-graphics-options, to choose the renderer.

Installation

  1. Close SimCity 4.
  2. Copy scvk.dll and scvk.ini into the Plugins folder in the SimCity 4 installation directory.
  3. Open SC4GraphicsOptions.ini and set: 
    Driver=OpenGL
ColorDepth=32
  4. Start the game. A scvk.log file appears beside scvk.dll.

Driver=OpenGL does not start the game's own unfinished OpenGL renderer. The game picks its renderer by an ID, and scvk registers under the OpenGL one with a higher version, so the game gets scvk instead.

ColorDepth=32 matters too: Windows no longer offers the 16-bit display modes the game uses by default.

To go back to DirectX, set Driver=DirectX. scvk still loads and its frame rate changes still apply, but the game draws with DirectX.

Configuring the plugin

Open scvk.ini in a text editor (e.g. Notepad). Each setting is explained in the file.

MaxFPS raises the game's frame rate caps, which are 30 at Turtle speed, 20 at Rhino and 15 at Cheetah. 0, the default, leaves them alone. A paused city is never held at 30 whatever this says.

UnlockRunningFPS lets MaxFPS go above about 60 while the city runs. The time comes out of the simulation, so the city simulates more slowly. Off by default.

LogLevel sets how much goes into scvk.log, from trace to off. info by default.

Enabled=false under [Admin] stops the game loading scvk at all. Set Driver=DirectX as well, or the game falls back to its own OpenGL renderer, which does not work.

The frame rate changes only apply to game version 641, and scvk checks the game's code holds what it expects before changing anything.

Compatibility

  • SCGL cannot be installed at the same time. Both register as the OpenGL renderer, so install one or the other.
  • SC4Fix works alongside scvk. The two change unrelated parts of the game.
  • sc4-disable-fps-limits works alongside scvk. If you use it, leave MaxFPS at 0.
  • DirectX wrappers such as dgVoodoo 2 only affect the DirectX renderer. scvk does not need one, and they can stay installed.

Troubleshooting

scvk.log is written beside scvk.dll, or in the Windows temp folder if the Plugins folder cannot be written to. It names the graphics card scvk chose and notes anything that went wrong.

If there is no log at all, the game did not load scvk. Check that the x86 Visual C++ Redistributable above is installed.

Please report problems at https://github.com/aspctt/scvk/issues, with your scvk.log, your graphics card and its driver version.
