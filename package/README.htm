scvk

A native Vulkan renderer for SimCity 4.

SimCity 4 shipped in 2003 with a DirectX 7 renderer and an unfinished OpenGL one. scvk replaces the renderer with one built on Vulkan, loaded as a DLL plugin through the game's own plugin system.

Status

Early preview. The region view, cities, menus and loading screens all draw, windowed, full screen or borderless, with lighting that matches the DirectX renderer. Players have run it on NVIDIA and AMD graphics cards, on Windows and on Linux, but expect problems on other hardware, and save often.

Known issues:

  • Scrolling while zoomed out was slower than DirectX, by roughly 40% on average in a large city. This version does less work for every draw, but it has not been measured again yet.
  • The interface flickered for a single frame now and then. This version should fix it, but that is not confirmed yet.
  • In fullscreen, PrintScreen now copies the game's picture to the clipboard, ready to paste, instead of opening the Snipping Tool, which took the game out of fullscreen, or copying the desktop, as it did on at least one AMD graphics card. Win+PrintScreen still saves a file in the Screenshots folder.
  • The game stopped responding once in testing, after leaving the Big City Tutorial. It has not happened again since.

System Requirements

  • SimCity 4 Deluxe, game version 641. Older versions are untested.
  • Windows 10 or 11, or Linux with Wine or Proton (Steam Play). On Linux, scvk.dll goes in the same Plugins folder inside the Wine or Proton prefix, and Wine needs its 32-bit Vulkan support (on Debian and Ubuntu, libvulkan1:i386 and mesa-vulkan-drivers:i386).
  • A graphics card and driver with Vulkan support.
  • sc4-graphics-options, to choose the renderer.

Installation

  1. Close SimCity 4.
  2. Copy scvk.dll into the Plugins folder in the SimCity 4 installation directory.
  3. Open SC4GraphicsOptions.ini and set: 
    Driver=OpenGL
ColorDepth=32
  4. Start the game. A scvk.log file appears beside scvk.dll.

Driver=OpenGL does not start the game's own unfinished OpenGL renderer. The game picks its renderer by an ID, and scvk registers under the OpenGL one with a higher version, so the game gets scvk instead.

ColorDepth=32 matters too: Windows no longer offers the 16-bit display modes the game uses by default.

To go back to DirectX, set Driver=DirectX. scvk still loads and its frame rate changes still apply, but the game draws with DirectX.

Settings

There is nothing to configure. scvk sets everything itself:

  • The game's frame rate caps (30 at Turtle speed, 20 at Rhino and 15 at Cheetah) are raised to the refresh rate of your screen, and a paused city is never held at 30.
  • Vertical sync is on, the faster graphics card is used on laptops with two, and ReShade works if it is installed.
  • Props and networks cast True3D shadows. -NativeShadowMasks:off goes back to the game's own shadows, and -NativeShadowMasks:replace also replaces the game's flat shadows and the terrain's shading, which is experimental.
  • scvk.log records the usual information.

Advanced users can still change these with SCD3D11's command line switches, added to the game's shortcut: -VSync:off, -GPU:default, -Borderless, -ReShade:off, -FlipModel:off and -LogLevel:trace (or debug, warn, error, off).

The frame rate changes only apply to game version 641, and scvk checks the game's code holds what it expects before changing anything.

Compatibility

  • SCGL cannot be installed at the same time. Both register as the OpenGL renderer, so install one or the other.
  • SC4Fix is fully compatible.
  • sc4-graphics-options is fully compatible, and is how you choose scvk as the renderer.
  • sc4-disable-fps-limits is no longer needed, but works alongside scvk: scvk leaves alone any cap it has already changed.
  • DirectX wrappers such as dgVoodoo 2 only affect the DirectX renderer. scvk does not need one, and they can stay installed.

Troubleshooting

scvk.log is written beside scvk.dll, or in the Windows temp folder if the Plugins folder cannot be written to. It names the graphics card scvk chose and notes anything that went wrong.

If there is no log at all, the game did not load scvk. Check that scvk.dll is in the Plugins folder of the SimCity 4 installation,.

Please report problems at https://github.com/aspctt/scvk/issues, with your scvk.log, your graphics card and its driver version.
