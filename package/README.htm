scvk

A native Vulkan renderer for SimCity 4.

SimCity 4 shipped in 2003 with a DirectX 7 renderer and an unfinished OpenGL one. scvk replaces the renderer with one built on Vulkan, loaded as a DLL plugin through the game's own plugin system.

Status

Early preview. The region view, cities, menus and loading screens all draw, windowed, full screen or borderless, with lighting that matches the DirectX renderer, and it is faster than DirectX, most of all zoomed out. ReShade's effects draw under the interface, and scd3d11's live shadows can be turned on. Players have run it on NVIDIA and AMD graphics cards, on Windows and on Linux, but expect problems on other hardware, and save often.

System Requirements

  • SimCity 4 Deluxe, game version 641. Older versions are untested.
  • Windows 10 or 11, or Linux through Wine or Proton.
  • A graphics card and driver with Vulkan support.

Installation

  1. Close SimCity 4.
  2. Copy scvk.dll into a Plugins folder, either the one in the SimCity 4 installation directory or the one in Documents\SimCity 4, but not both.
  3. Start the game. A scvk.log file appears beside scvk.dll.

That is all: the game picks scvk by default. On a machine without Vulkan, the game keeps its own DirectX renderer.

With sc4-graphics-options, both Driver=DirectX and Driver=OpenGL select scvk. Driver=OpenGL does not start the game's own unfinished OpenGL renderer, since scvk registers under that ID with a higher version. scvk draws in 32-bit whatever ColorDepth says. Set it to 32 for windowed play: at 16, the game switches to fullscreen whenever the desktop runs at a different depth.

To go back to DirectX, remove scvk.dll, or see Enabled below.

Settings

scvk needs no settings. Launch options change a few things for one launch, and scd3d11's options work the same way:

  • scvk starts the game borderless, covering the main monitor. -w gives a window and -f exclusive fullscreen, at the size in the game's options, and -r sets a size of its own. With sc4-graphics-options installed, its WindowMode decides instead.
  • -NativeShadowMasks:all turns on live shadows for True3D props and network pieces. They are off by default, since while they are on every scroll, zoom and turn makes the game redraw the whole city. -NativeShadowMasks:replace adds the experimental shadow registry and terrain shadows.
  • -MaxFPS:<n> sets the game's frame rate caps, which are 30 at Turtle speed, 20 at Rhino and 15 at Cheetah. scvk raises them to the display's refresh rate by default, and -MaxFPS:off keeps the game's. A paused city is never held at 30 whatever this says.
  • -VSync:off, -GPU:default, -FlipModel:off and -ReShade:off work as they do in scd3d11.
  • -LogLevel:<level> sets how much goes into scvk.log, from trace to off. info by default.

The scvk.ini in the zip is optional. Copy it beside scvk.dll if you want to change a setting, and scvk reads it when it is there. A scvk.ini from 0.2 keeps working, but its MaxFPS=0 keeps the game's frame rate caps; delete that line for the display's refresh rate.

MaxFPS under [scvk] does what -MaxFPS does, where 0 keeps the game's caps.

Use32BitDepth=true under [scvk] gives the depth buffer 32 bits instead of the 16 the DirectX renderer uses. Surfaces that sit very close together stop banding, but lights laid exactly on a model can leave thin lines after scrolling.

LogLevel under [scvk] does what -LogLevel does.

Enabled=false under [Admin] stops the game loading scvk at all, which brings back the DirectX renderer. If SC4GraphicsOptions.ini says Driver=OpenGL, set it to DirectX as well, or the game falls back to its own OpenGL renderer, which does not work.

The frame rate changes only apply to game version 641, and scvk checks the game's code holds what it expects before changing anything.

Compatibility

  • SCGL cannot be installed at the same time. Both register as the OpenGL renderer, so install one or the other.
  • SC4Fix is fully compatible.
  • sc4-graphics-options is fully compatible, though no longer needed to choose scvk.
  • scd3d11 can be installed alongside. It keeps the DirectX slot, so Driver=DirectX selects scd3d11 and Driver=OpenGL selects scvk.
  • sc4-disable-fps-limits works alongside scvk, and the caps it sets stay.
  • ReShade 6, installed for Vulkan with full add-on support, draws its effects under the interface, with the city's depth for effects that read it. Without full add-on support, its effects cover the interface too.
  • DirectX wrappers such as dgVoodoo 2 only affect the DirectX renderer. scvk does not need one, and they can stay installed.

Troubleshooting

scvk.log is written beside scvk.dll, or in the Windows temp folder if the Plugins folder cannot be written to. It names the graphics card scvk chose and notes anything that went wrong.

If there is no log at all, the game did not load scvk. Check that scvk.dll is directly in a Plugins folder, not in a subfolder, and that Enabled is not set to false in scvk.ini.

Please report problems at https://github.com/aspctt/scvk/issues, with your scvk.log, your graphics card and its driver version.
